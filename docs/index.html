스킬을 골라 설치

스킬을 고르고 설치할 도구를 정한 뒤 설치하기를 누르세요. 브라우저가 폴더를 하나 고르라고 물으면 아래에 표시된 skills 폴더를 고르면 됩니다. 파일은 GitHub에서 바로 받아 그 폴더에 씁니다.

설치할 도구

한 곳만 골라도 됩니다. OpenCode는 Claude Code 폴더도 함께 읽습니다.

스킬

버튼으로 설치되지 않을 때

폴더에 바로 쓰는 기능은 Chrome과 Edge에서만 됩니다. Firefox나 Safari라면, 또는 폴더를 고르기 번거롭다면 아래 명령을 복사해 터미널에 붙여 넣으세요. 위에서 고른 스킬과 도구가 그대로 반영됩니다.

설치한 뒤

  1. OpenCode, Claude Code, Cursor를 이미 켜 두었다면 한 번 다시 시작합니다.
  2. 새 대화에서 스킬이 하는 일을 부탁하면 알아서 불러옵니다. 예를 들어 confidence는 "확신도 붙여서 답해 줘"로 확인할 수 있습니다.
  3. 같은 스킬을 다시 설치하면 이전 폴더를 지우고 새 파일로 바꿉니다. 업데이트도 같은 방법으로 합니다.
스킬 원본은 GitHub 저장소에 있습니다. doc-coauthoring은 anthropics/skills에서 받습니다.
